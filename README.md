# Sorrisa Odontologia

Projeto conceito de site para clínica odontológica, criado pela **Growthfy Tech** para portfólio.

- Sorriso ilustrado flutuante na abertura
- Agendamento online (escolha de atendimento, dia e horário)
- Tratamentos com preços, primeira consulta minuto a minuto, horários com aviso de "aberto agora" e dúvidas frequentes
- Tema claro e escuro, responsivo para celular

Site estático em um único arquivo (`index.html`), pronto para publicar na Vercel, Netlify, GitHub Pages ou Hostinger.

> Clínica, endereço, telefone e valores são fictícios.
